## Description

The Theme Builder allows you to create own themes directly in your browser. 


### Features

- Use existing themes to apply your changes (e.g.  our Community or Enterprise Theme)
- Adjust colors with color codes or pick them from a color pallet
- Adjust the width of the space bar (Enterprise Edition only)
- Create Favicons (Android, Microsoft, Apple)
- Add Wallpapers to your login page
- Automatically compiles LESS file
